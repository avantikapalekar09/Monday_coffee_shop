# ☕ Monday Coffee Shop Sales Analysis

## 📌 Project Overview

The **Monday Coffee Shop Sales Analysis** project focuses on analyzing coffee shop sales data to identify sales trends, customer preferences, and overall business performance. The analysis helps understand which products, categories, and time periods contribute most to revenue.

## 🎯 Project Objective

* Analyze overall coffee shop sales performance.
* Identify top-selling products and product categories.
* Understand sales trends by day and time.
* Analyze customer purchasing patterns.
* Identify opportunities to improve sales and business performance.

## 📊 Key Analysis

* Total Sales and Total Orders
* Average Order Value
* Top-Selling Products
* Sales by Product Category
* Sales by Month/Day
* Sales by Store Location
* Peak Sales Hours
* Customer Order Trends

## 🛠️ Tools & Technologies

* **Excel** – Data cleaning and initial analysis
* **SQL** – Data querying and analysis
* **Power BI / Tableau** – Data visualization and dashboard creation
* **GitHub** – Project documentation and portfolio

## 📈 Key Insights

The analysis provides useful insights into:

* Which products generate the highest revenue.
* Which categories have the strongest sales performance.
* The busiest days and hours for the coffee shop.
* Customer ordering patterns.
* Areas where the business can improve sales and operational efficiency.

## 💡 Business Impact

This project demonstrates how data analysis can be used to transform raw sales data into meaningful business insights. The findings can help coffee shop management make better decisions related to **product offerings, staffing, inventory planning, and sales strategies**.
